# NX12 Export Dashboard

## Project Overview
A dark-themed Tkinter dashboard for automating Siemens NX 12.0 file exports on Windows with exact manifest verification.

## Build Command
```bash
python -m PyInstaller --onefile --windowed --add-data "src;src" --name NX12_Dashboard_new src/nx12_dashboard.py
```
Output: `dist/NX12_Dashboard_new.exe` (or root `NX12_Dashboard_new.exe`)

## Key Files
- `src/nx12_dashboard.py` — Main GUI (Tkinter Dark Theme, responsive horizontal resizing, High-DPI support, Run ID validation)
- `src/export_pdf_NX12.py` — NX12 Journal: PRT → PDF (with Drafting mode switch, stale pre-cleanup, atomic manifest)
- `src/export_step_NX12.py` — NX12 Journal: PRT → STEP (AP214 format, portable `.def` resolution, stale pre-cleanup, atomic manifest)
- `src/export_dwg_NX12.py` — NX12 Journal: PRT → DWG (`DrawingList` multi-sheet separation, indexed collision-free names `Part_01_Sheet.dwg`, >3MB threshold, atomic manifest)
- `src/import_stp_export_iges_NX12.py` — NX12 Journal: STP → IGES (true structural sanity validation checking column 72 Section cards `G`, `D`, `P`, `T`, atomic manifest)

## Conventions
- UI text: 100% Simplified Chinese (zh-CN)
- Code: 100% English
- Comments: English
- NX12 Journal scripts: IronPython 2.x and Python 3 compatible (`# -*- coding: utf-8 -*-`) with safe `try: import NXOpen except ImportError:` guards

## NX12 Journal Pattern (Safe Resource Management & Atomic Manifest)
```python
# -*- coding: utf-8 -*-
try:
    import NXOpen
except ImportError:
    NXOpen = None
import os
import sys
import json

def write_result_json(folder, result_data, lw=None):
    try:
        json_path = os.path.join(folder, "export_result.json")
        tmp_path = json_path + ".tmp"
        with open(tmp_path, "w") as f:
            json.dump(result_data, f, indent=2)
        if os.path.exists(json_path):
            try:
                os.remove(json_path)
            except:
                pass
        os.rename(tmp_path, json_path)
    except Exception as e:
        if lw is not None:
            try:
                lw.WriteLine("  ERROR writing export_result.json: " + str(e))
            except:
                pass

def main():
    theSession = NXOpen.Session.GetSession()
    lw = theSession.ListingWindow
    lw.Open()

            # record failure in result_data
            pass
        finally:
            if builder is not None:
                try:
                    builder.Destroy()
                except:
                    pass
            if workPart is not None:
                try:
                    workPart.Close(NXOpen.BasePart.CloseWholeTree.TrueValue, NXOpen.BasePart.CloseModified.CloseModified, None)
                except:
                    pass
```

## Result Manifest Schema (`export_result.json`)
Every journal writes `export_result.json` into its destination subfolder (`PDF/`, `STEP/`, `IGES/`, `DWG/`):
```json
{
  "operation": "prt_to_pdf | prt_to_step | stp_to_iges | prt_to_dwg",
  "run_id": "a1b2c3d4e5f6",
  "total": 10,
  "success": 8,
  "failed": 1,
  "skipped": 1,
  "files": [
    {
      "input": "filename.prt",
      "output": "relative/path" or null,
      "status": "success | failed | skipped",
      "error": "Error description or null"
    }
  ]
}
```

## Running Scripts
Scripts are called via `run_journal.exe`:
```cmd
run_journal.exe <script.py> -args <folder_path> <run_id>
```

## Important Notes
- DWG export skips PRT files > 3MB (user must export manually, configured via `MAX_PRT_SIZE_MB` in `export_dwg_NX12.py`)
- Drawing sheet names are sanitized to prevent invalid Windows filename characters (`\ / : * ? " < > |`) and prefixed with sheet index (`%02d`) to eliminate collisions
- Log files are cleaned up automatically within each journal script
- Target: Siemens NX 12.0 on Windows (with portable path detection via `UGII_BASE_DIR` or default paths)
